# Weavatrix Refactor 0.1.4

This release hardens the architecture and release surface of the transactional
write boundary without changing the public MCP tool contract.

## Architecture

- Added a strict, checked-in Weavatrix architecture contract for the edit-plan
  model, platform adapters, plan engines, application workflows, and MCP
  adapter.
- Enforced zero runtime cycles, at most 300 lines per code or test file, and at
  most 100 lines per function, with no exceptions or baseline.
- Split the four oversized planner functions into focused validation, session,
  scan, selection, edit-construction, and evidence-assembly helpers.

## Package and documentation

- Expanded installation, MCP configuration, programmatic composition,
  architecture, safeguards, and package-boundary documentation.
- Aligned npm and MCP Registry descriptions and versions.
- Included the architecture contract in the published npm artifact.

Weavatrix Refactor remains MIT-licensed and depends on the MIT-licensed
`weavatrix-js ^0.3.15` extension host.
