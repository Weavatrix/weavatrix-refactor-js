# Weavatrix Refactor JS 0.1.7

This is the first release under the `weavatrix-refactor-js` package and
`sergii-ziborov/weavatrix-refactor-js` repository. It continues the JavaScript
refactoring engine while the canonical `weavatrix-refactor` package moves to a
native Rust MCP host, mirroring the `weavatrix` / `weavatrix-js` split.

## Migration

- The npm package, executable, MCP Registry identifier, repository links, skill
  name and release workflow now consistently use `weavatrix-refactor-js`.
- Install and run with `npx -y weavatrix-refactor-js <repoRoot>`.
- Existing users can keep `weavatrix-refactor@0.1.6` pinned for the identical
  package under the old name.
- The refactor home moved from `~/.weavatrix-refactor` to
  `~/.weavatrix-refactor-js`. This is deliberate: the Rust host will own the old
  path, and two different implementations must never share a repository lock, a
  confirmation-token store, or a rollback journal. A rollback bundle written by
  0.1.6 stays in the old directory — finish or discard any pending rollback
  before upgrading, or point `WEAVATRIX_REFACTOR_HOME` at the old path.

## Unchanged

The 11 tools, their schemas, the `weavatrix.edit-plan.v1` envelope, every result
state, and the three write gates are exactly those of 0.1.6, including its fixes:
typed `INVALID_ARGS` refusals, honest rename coverage (`COMPLETE` now means every
candidate file was proven), the pooled language server, and text-mode output that
carries counts and verdicts.

The host dependency remains `weavatrix-js` 0.3.15.
